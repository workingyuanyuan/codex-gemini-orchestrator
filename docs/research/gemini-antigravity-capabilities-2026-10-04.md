## Capability layers

Gemini 3.8 Flash's API accepts text, images, audio, video and PDFs and produces text. Its documented input/output limits are 1,048,576/65,536 tokens. It supports Search/Maps grounding, URL context, function calling, code execution, file search and preview computer use. Image/audio generation and Live API require other models. These API features do not establish what the subscription CLI exposes. [Model specification](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)

Antigravity separately provides agent tools and plugins. Its image-generation route uses Nano Banana 2, independently of the selected reasoning model. A Gemini worker invoking that route is using another model/service. [Antigravity models](https://antigravity.google/docs/models/)

## Routing guidance

The skill selects native Antigravity capabilities by task fit and verifies tool access in the executing session. Its [capability contracts](../../versions/6.1-sol-gemini3.8flash/skills/model-routing-and-delegation-agy/references/gemini-capabilities.md) supply the dispatch and acceptance requirements.

- Gemini medium: README narrative, user-facing copy, localization, self-contained research and straightforward media inspection through native tools.
- Gemini high: ambiguous multimodal interpretation, deeper synthesis or reasoning-intensive research.
- Browser: rendered-page inspection and interaction through the built-in workflow after a successful connection check.
- Boost: bounded investigation or implementation with independent verification, using supervised streaming and child cleanup.

Ordinary workers complete assignments directly. Browser and Boost contracts authorize their specific built-in descendants and require lifecycle evidence.
